# 📚 Atividade Prática – Levantamento de Requisitos

---

# 👥 1. Quem utilizará o sistema?

O sistema será utilizado pelos seguintes usuários:

* 📝 **Secretários da escola**
* 👨‍🏫 **Professores**
* ⚙️ **Administradores**

---

# ⚙️ 2. Cite 3 requisitos funcionais (o que o sistema deve fazer).

Os principais requisitos funcionais do sistema são:

### ✅ Cadastrar, editar e excluir alunos

Permitir o gerenciamento completo do cadastro dos alunos.

### ✅ Registrar a frequência dos alunos

Possibilitar que os professores registrem a presença e ausência dos estudantes.

### ✅ Consultar e emitir relatórios

Gerar relatórios com informações dos alunos, como dados cadastrais e frequência.

---

# 🔒 3. Cite 2 requisitos não funcionais (como o sistema deve funcionar).

Os requisitos não funcionais definidos são:

### 🎨 Interface simples e intuitiva

O sistema deve ser fácil de aprender e utilizar por todos os usuários.

### 🔐 Segurança dos dados

O acesso ao sistema deve ser protegido por login e senha para garantir a privacidade das informações dos alunos.

---

# 💡 4. Explique, em poucas palavras, por que é importante levantar os requisitos antes de desenvolver um software.

O levantamento de requisitos é uma etapa essencial do desenvolvimento de software, pois permite:

* ✔️ Compreender as necessidades dos usuários.
* ✔️ Evitar erros durante o desenvolvimento.
* ✔️ Reduzir retrabalho e custos.
* ✔️ Garantir que o sistema atenda aos objetivos do projeto.
* ✔️ Melhorar a qualidade do software entregue.

---

## 📌 Conclusão

O levantamento de requisitos é fundamental para o sucesso de qualquer projeto de software. Ele orienta o desenvolvimento, facilita a comunicação entre a equipe e os usuários e aumenta as chances de entregar um sistema que realmente atenda às necessidades da escola.
